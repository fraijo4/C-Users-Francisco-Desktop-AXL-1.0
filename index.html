Leer fotos y capturas con IA

Para que la página lea un schedule desde una foto o screenshot necesita una llave de la API de Claude (platform.claude.com → API keys). La llave se guarda solo en este navegador y no se incluye en los respaldos.

Aviso: la lectura de fotos se cobra a tu cuenta de Claude por cada imagen. Si abres la página desde la liga de claude.ai, el navegador bloquea esta conexión por seguridad; usa la versión que abres desde tu computadora o GitHub Pages.
